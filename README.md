# Telco Customer Churn Analytics

## 📌 Project Overview

An end-to-end Data Analytics project focused on understanding customer churn, identifying high-risk customer segments, and developing data-driven retention strategies.

## 🎯 Business Problem

Which customers are most likely to churn, what factors drive churn, and how can the business improve customer retention?

## 🛠️ Tools & Technologies

- Excel – Data Cleaning & Analysis
- MySQL – SQL Analysis
- Python – Exploratory Data Analysis
- Power BI – Interactive Dashboard
- GitHub – Project Documentation

## 📊 Key Metrics

- Total Customers: 7,032
- Churned Customers: 1,869
- Retained Customers: 5,163
- Overall Churn Rate: 26.58%
- Average Monthly Charges: $64.76
- Average Tenure: 32 months

## 🔍 Key Business Insights

1. Month-to-month customers have the highest churn rate.
2. Fiber-optic customers show significantly higher churn.
3. Customers in their first year have the highest churn risk.
4. Electronic-check customers have the highest churn rate.
5. Senior customers have higher churn than non-senior customers.

## 💡 Retention Recommendations

1. Strengthen early-tenure onboarding.
2. Reduce month-to-month churn through contract incentives.
3. Improve the fiber-optic customer experience.
4. Address payment-related friction.
5. Target high-risk customers with proactive retention campaigns.
